# Gulf Lingo

An interactive Emirati and Gulf Arabic learning application.

## Features
- 60 lessons across 10 units
- Vocabulary exercises
- Multiple-choice quizzes
- Arabic sentence-building exercises
- Listen & Build activities
- XP and learning progress

## Audio
Arabic pronunciation and interface sound effects are being developed.

## Development
Run locally:

python3 -m http.server 8000

Open http://localhost:8000
